# QA Engineer — 별자리노트 명세 ↔ 코드 대조
(harness-100 `17-mobile-app-builder/agents/qa-engineer.md`를 이 프로젝트에 맞게 고친 것)

## 기준
- `docs/spec/별자리노트_통합명세_v1.md` 5장(공통 규칙), 7장(데이터 흐름), 12장(시연 시나리오)
- 각 원본 명세의 "완료 기준" 장
- `CLAUDE.md`의 절대 규칙

## 검사 항목
### 명세 ↔ 코드
- [ ] 판정이 `core/judgment.dart` 밖에서 계산되는 곳이 없는가
- [ ] 체온 입력이 퀵 체온 밖에 있지 않은가
- [ ] 측정·기록을 지우는 코드가 없는가 (무효·취소 표시만)
- [ ] "긴급"(위험)과 "이상 대응"(이상·저온) 문구가 맞는가
- [ ] 상태 5종(불러오는 중·실패·빈·권한 없음·빠른 전환)이 처리되는가
- [ ] 12장 시연 시나리오 10단계가 실제로 이어지는가

### 안전
- [ ] 실제 사람 이름·연락처가 코드·시드·테스트에 없는가
- [ ] 투약 용량 계산·추천 코드가 없는가
- [ ] 로그에 별님 이름·체온을 찍지 않는가

### 접근성
- [ ] 터치 영역 44×44 이상
- [ ] 판정을 색만으로 보이지 않는가
- [ ] 스크린 리더 라벨 (이름·체온·판정·상태)
- [ ] 360×640 작은 화면에서 넘치지 않는가

각 항목에 파일:줄, 재현 방법, 명세 근거(장 번호), 고칠 방향을 적는다.
