# 별자리노트 — 일정 기능

기능 담당 범위: 반별 일정 화면, 별님 하루 일정, 달력 이동, 파일로 일정 올리기, 일정에 연결된 체온 측정 시점 표시

기준일: 2026-11-12

이 문서는 전체 앱 명세를 취합할 때 사용하는 기능 설명 자료다. 독립 앱 개발 프롬프트가 아니다. 기술 스택·공통 데이터 모델·API·디자인 시스템은 전체 앱 통합 설계에서 결정되며, 아래는 그 구조 안에서 유지되는 기능의 동작이다.

| 별자리노트_일정_화면시제품.html | 브라우저에서 조작 가능한 화면 참고 자료 |

HTML은 byeoljari-note_1028.html의 ‘반별 일정’ 앱 화면만 떼어 온 것이다. 화면 구조와 모양은 원본 그대로이고, 반 이름·별님 이름·체온 판정 표시는 다른 담당 자료(퀵 체온, 이상 대응)와 맞췄다. HTML 구현 기술이 실제 앱의 기술 스택을 정하는 것은 아니다.

## 1. 이 문서의 범위

| 포함 (내 담당) | 포함 안 함 (다른 담당과 경계) |
| --- | --- |
| 하단 메뉴의 ‘일정’ 탭 화면 전체 | 퀵 체온 입력 화면, 다이얼, 0.5초 눌러 기록 (퀵 체온 담당) |
| 반 탭, 별님 카드 목록, 별님 하루 일정 | 체온 판정(평소·주의·이상·위험·저온)과 기저치 계산 (기저치 담당) |
| 달력으로 날짜 이동 | 이상 건 알림·확인·담당·대응 단계·종료 (이상 대응 담당) |
| 파일로 일정 올리기(올리기 → 표 확인 → 반영) | 알림 보내기와 알림 조건 (알림 담당) |
| 일정에 붙은 ‘체온 측정 시점’ 표시 | 사무국 웹의 일정 편집·전체 시간표·현황판 (웹 담당) |
| 카드에 보이는 체온 상태·이상 대응 중 표시(읽기만) | 인수인계·아카이브 화면과 기록 (인수인계·아카이브 담당) |

> 다른 담당자에게: 일정은 체온을 ‘판정’하지 않는다. 카드에 보이는 체온과 판정 단계는 기저치 담당이 넘겨주는 값을 그대로 보여준다. 진행 중인 이상 건이 있는지도 이상 대응 쪽 데이터를 읽어서 표시만 한다.

## 2. 하루 흐름에서의 역할

발표에서 정한 방향에 따라 일정은 체온 측정을 일과에 녹여 업무 부담 없이 돌아가게 하는 보조 기능이다. 그래서 일정 화면에서도 ‘지금 무엇을 하는지’ 다음으로 ‘체온을 언제 재는지’가 가장 눈에 띄게 보이도록 한다. 일정 때문에 체온 기능보다 먼저 보이는 정보는 만들지 않는다.

## 3. 화면 구성과 기본값

상단부터 제목과 ‘파일로 일정 올리기’ 버튼, 반 탭, 날짜 줄(오늘 날짜와 달력 펼침), 별님 카드 목록, 하단 메뉴다.

- 하단 메뉴: 인수인계 · (가운데) 퀵 체온 · 일정. 위치와 모양은 퀵 체온 명세와 같고, 일정 탭이 눌린 상태로 표시된다.
- 기본 반: 로그인한 선생님의 담당 반. 반 탭에 ‘내 반’이 붙는다.
- 기본 날짜: 오늘.
- 반 이름은 별자리 이름을 쓴다. 시연 예시는 양자리반·황소자리반·쌍둥이자리반·게자리반이다(퀵 체온 시제품과 같은 이름).
- 다른 반도 볼 수 있다. 조회 권한은 공통 권한 체계를 따른다.
- 달력을 펼치면 월 단위 날짜 선택이 나오고, 날짜를 고르면 접힌다. 오늘이 아니면 ‘오늘로’ 버튼이 보인다. 일정이 있는 날에는 점이 찍힌다.
- 맨 아래에 ‘보기 전용 · 일정 변경은 사무국 웹에서 해요’를 둔다.

## 4. 별님 카드

한 장에 프로필, 이름, 지금 일정, 다음 일정, 오전·오후 체온 상태가 들어간다. 2열로 나열된다.

| 표시 | 뜻 |
| --- | --- |
| 오전 ✓ 36.5° 평소 | 기록됨. 판정이 평소 |
| 오전 ! 37.4° 주의 | 기록됨. 판정이 주의 |
| 오전 ▲ 38.2° 이상 | 기록됨. 판정이 이상. 카드 테두리가 주황색 실선 |
| 오전 ⚠ ○○° 위험 | 기록됨. 판정이 위험. 카드 테두리가 빨간색 실선 |
| 오전 ▼ 35.4° 저온 | 기록됨. 판정이 저온. 카드 테두리가 파란색 실선 |
| 오전 미기록 + ‘측정 전’ | 측정 시간이 지났는데 기록이 없음. 회색 점선 테두리 |
| 오후 예정 | 아직 측정 시간 전 |
| 카드 오른쪽 위 ‘이상 대응 중’ | 이 별님에게 진행 중인 이상 건이 있음. 눌러서 이상 건 상세로 가는 연결은 이상 대응 담당과 정한다 |

- 색만으로 구분하지 않고 기호와 글자를 함께 쓴다.
- 판정 단계 이름과 색은 이상 대응 자료와 같다. 기준값은 일정이 정하지 않는다.
- ‘지금’ 일정은 현재 시각이 일정 시간 안에 있을 때 붉은 글씨로 보인다. 없으면 반 생활실로 표시한다.
- 오늘이 아닌 날짜에서는 지금·다음 대신 ‘하루 일정 끝’ 또는 ‘일정 보기’를 보인다.
- 카드를 누르면 별님 하루 일정으로 들어가고, 뒤로 가기로 같은 반 목록에 돌아온다.
- 주말에는 식사와 여가 활동만 있다는 안내가 나온다.

## 5. 별님 하루 일정

머리에 별님 이름·날짜·일정 개수와 오전·오후 체온 상태가 있고, 아래로 시간 순서 목록이 이어진다.

- 한 줄: 시작·종료 시각, 종류 색 태그, 제목, 장소, 담당자.
- 종류: 식사, 학교, 치료·교육, 예체능, 목욕, 생활.
- 진행 중인 일정은 붉은 테두리와 ‘지금’, 끝난 일정은 흐리게와 ‘지남’으로 표시한다.
- 체온 측정이 걸린 일정에는 ‘체온 측정 · 오전 체온’, ‘오후 체온 · 목욕 전’, ‘오후 체온 · 귀가 후’ 같은 줄이 붙는다. 이 줄이 알림 담당이 쓸 측정 시점의 기준이 된다.
- **[제안, 미확정]** 이 줄을 누르면 해당 별님이 선택된 채 퀵 체온으로 이동한다. 퀵 체온 명세는 진입을 중앙 버튼으로만 정했으므로 퀵 체온 담당과 정한다. 이동하더라도 반 측정 권한이 없는 반이면 이동하지 않고 안내만 보인다.
- 통학하는 별님과 주말은 일정 패턴이 다르다.

## 6. 파일로 일정 올리기

‘파일로 일정 올리기’를 누르면 아래에서 시트가 올라온다.

1. 올리기: hwpx 또는 엑셀 파일을 고른다.
2. 표 확인: 날짜·시간·프로그램·장소·담당·대상이 표로 정리되어 나온다. 선생님이 내용을 확인한다.
3. 반영: ‘일정에 반영’을 누르면 반별 일정에 들어간다. ‘다시 올리기’로 되돌아갈 수 있다.

시제품에는 실제 파일 해석이 없다. 예시 5건이 고정으로 표시되고 반영해도 일정은 바뀌지 않는다.

**[확인 필요]** 파일 해석을 이번 개발 범위에 넣을지, 사무국 웹으로 미룰지, 1조와 연동할지는 팀에서 정한다. 앱에서 올린 일정을 앱이 직접 고칠 수 있게 할지도 같이 정한다(지금은 보기 전용).

## 10. 다른 기능과의 연결

| 공통 영역 | 필요한 연결 |
| --- | --- |
| 로그인 사용자 | 선생님 ID, 기관, 담당 반 |
| 반과 별님 관리 | 반 이름, 별님 ID·이름·프로필, 반별 목록과 순서 |
| 퀵 체온 | 저장된 체온 기록(별님 ID, 반 ID, 체온, 측정 시각)을 읽어 카드 오전·오후 칸에 표시 |
| 기저치(판정) | 체온 한 건의 판정 단계(평소·주의·이상·위험·저온)를 받아 표시 |
| 이상 대응 | 별님별 ‘진행 중인 이상 건 있음’ 여부를 읽어 카드에 표시 |
| 알림 | 일정에 붙은 체온 측정 시점을 알림 조건에 제공. 알림 발송은 알림 담당 |
| 인수인계·아카이브 | 담임이 바뀌어도 같은 별님 ID로 일정이 이어짐 |
| 공통 하단 내비게이션 | ‘일정’ 탭 이동. 새 탭을 만들지 않음 |

반을 빠르게 바꿀 때 이전 반의 늦은 응답이 현재 목록을 덮어쓰지 않아야 한다. 목록 로딩·실패·빈 반·일정 없음 상태에서도 이전 반의 별님을 현재 반 소속처럼 표시하지 않는다.

**[확인 필요]** 이상 대응 자료에서 “시제품의 일정 예시 ‘09:00 등원’은 거주시설과 맞지 않다”는 지적이 있었다. 이 시제품의 일정에는 ‘등원’이 없고, 학교 다니는 별님은 ‘울산행복학교 · 통학 · 15:00 귀가’로 표시된다. 이 표현이 혜진원 실제 일과와 맞는지 현장 확인이 필요하다. 또 퀵 체온 명세는 별님을 ‘아동’으로 적고 있는데 거주인은 성인도 포함하므로 용어를 ‘거주인’ 기준으로 통일하자는 의견(이상 대응 자료)에 이 문서도 따른다.

## 12. 완료 판단 기준

- 담당 반·오늘 날짜로 처음 진입하고 ‘내 반’이 표시된다.
- 반을 바꾸면 카드 목록이 그 반 별님으로 즉시 바뀐다.
- 카드에서 오전·오후 체온 상태(기호+글자+색)와 지금·다음 일정이 보인다.
- 이상·위험·저온 판정과 미기록은 카드 테두리로 구분된다.
- ‘이상 대응 중’ 표시가 진행 중인 이상 건이 있는 별님에게만 나온다.
- 카드를 누르면 하루 일정이 시간 순으로 나오고 현재 일정이 강조된다.
- 달력으로 다른 날짜를 고르면 그날 일정이 나오고 ‘오늘로’로 돌아온다.
- 체온 측정 시점이 하루 일정에서 눈에 띈다.
- 파일 올리기에서 올리기 → 표 확인 → 반영 흐름이 끊기지 않는다.
- 하단 메뉴가 퀵 체온 시제품과 같은 자리·같은 이름이고 내용과 겹치지 않는다.
- 작은 화면, 큰 글자 설정, 스크린 리더에서 이름·체온 상태·일정 시간이 읽힌다.

## 13. 팀에서 정할 사항

1. 앱 일정을 보기 전용으로 둘지, 선생님이 간단히 추가·수정할 수 있게 할지.
2. 파일(hwpx·엑셀) 해석을 이번 범위에 넣을지, 누가 맡을지.
3. 일정의 체온 측정 줄에서 퀵 체온으로 바로 이동할지(퀵 체온 담당과).
4. 카드에 이상 대응 중 표시를 둘 때 눌렀을 때 어디로 갈지(이상 대응 담당과).
5. 체온 측정 시점을 별님별로 정할지 반 전체로 정할지(알림 담당과).
6. 학교·통학 일정 표기가 혜진원 실제와 맞는지.
7. 일정 항목의 ID·필드 이름을 공통 데이터 모델에 어떻게 맞출지.
