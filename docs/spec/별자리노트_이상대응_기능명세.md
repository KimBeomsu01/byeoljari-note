## 0. 한눈에 보기

- 체온이 **'이상' 이상**으로 판정되면 앱이 **이상 건(케이스)** 하나를 자동으로 만들어요.
- 이상 건이 생기면 **간호사·사무국(야간에는 당직)**에게 알림이 가요.
- 받은 사람은 **[확인했어요]**를 누르고, 한 사람이 **[제가 맡을게요]**로 담당자가 돼요.
- 담당자는 혜진원에 **이미 있는 대응 경로**를 따라 단계를 올려요.
  **① 관찰·재측정 → ② 원내 조제 → ③ 원장 처방 → ④ 인근 병원**
- 언제든 **[투약 지침 보기]**로 간호사·원장님이 **미리 써둔** 지침을 볼 수 있어요. 앱은 용량을 계산하거나 추천하지 않아요.
- **버튼을 한 번 누를 때마다 "누가 · 언제 · 무엇을" 기록이 하나씩** 남아요. 기록은 지우지 않고, 잘못 누른 경우에는 "취소" 기록을 하나 더 남겨요.
- 체온이 평소로 돌아오면 **[대응 종료]**로 이상 건을 닫아요.

## 1. 이 문서의 범위

| 포함 (내 담당) | 포함 안 함 (다른 담당과 경계) |
|---|---|
| 이상 판정 직후 생활관 화면에 뜨는 **경고 시트** | 퀵 체온 입력 화면 자체: 반·별님 고르기, 다이얼, 0.5초 눌러 기록 (퀵 체온 담당) |
| 알림 보내기·다시 보내기(에스컬레이션) | 기저치 계산 방법 (F3 담당, 01번 문서 4장) |
| 이상 건 상세 화면 (확인·담당·단계·투약·재측정·종료) | 투약 지침을 **작성·수정**하는 화면 (F1 별님 프로필 담당) |
| 투약 지침 **보기** 시트 | 사무국 현황판 전체 레이아웃 (F5 담당). 단, 현황판 안의 **"진행 중인 이상 건" 영역**은 내 담당 |
| 별님 카드 안의 **대응 이력 타임라인** | 엑셀 내보내기 (F6 담당). 단, 내보낼 **대응 기록 항목**은 이 문서 8장을 따름 |

> 다른 담당자에게: 퀵 체온은 **기록이 저장된 뒤** 체온 기록(별님 ID, 반 ID, 체온, 측정 시각, 기록자)을 넘겨주면 돼요. 판정 단계(평소/주의/이상/위험/저온)는 기저치(F3)로 계산하고, 그다음부터는 이 문서가 맡아요.

### 1-1. 퀵 체온 입력과 맞춘 점 (v0.2)

| # | 부딪히던 점 | 퀵 체온 명세 | 이 문서의 이전 내용 | 이렇게 맞춤 |
|---|---|---|---|---|
| 1 | 입력 방식 | 원형 **다이얼**로 0.1℃씩 조절, **0.5초 눌러** 기록 | "F2 숫자패드" | 숫자패드 표현을 모두 지우고 **퀵 체온 화면을 그대로** 써요. 재측정(S6)도 퀵 체온 화면으로 열어요 |
| 2 | 저장 직후 화면 | 저장 성공 → **배경 초록 + "기록 완료"**. 초록은 "기록 완료"이지 정상 판정이 아님. 다음 별님으로 자동 이동 안 함 | 저장하면 S1 경고 시트가 뜸 | **초록 "기록 완료"를 먼저 보여준 뒤**, 판정이 이상·위험·저온이면 그 위에 **S1 경고 시트**를 올려요. 초록 배경만 보고 "정상"으로 오해하지 않도록 하기 위해서예요. S1을 닫으면 퀵 체온 화면으로 돌아가고, 해당 별님 프로필에 판정 색 점을 표시해요 |
| 3 | 저장한 값을 고쳐서 다시 기록 | "새 재측정과 기존 기록 정정의 구분은 공통 정책" (미정) | 재측정 = 이상 건에 붙임, 오측정 = [잘못 쟀어요] | **[제안]** 퀵 체온에서 다시 0.5초 눌러 기록하면 **항상 새 측정**으로 저장해요 (기존 기록은 그대로 둬요). 잘못 잰 값을 바로잡는 일은 S1의 **[잘못 쟀어요]**로만 해요. 공통 정책 회의에서 확정해요 |
| 4 | 하단 메뉴 | **인수인계 · (가운데) 퀵 체온 · 일정** 3개 | 화면 위치를 정하지 않음 | 새 탭을 만들지 않아요. 이상 건은 **인수인계 탭 맨 위**에 고정 카드로, 알림은 화면 위 **🔔**로 보여줘요 (5장 표) |
| 5 | 반 이름·예시 데이터 | 양자리반·황소자리반·쌍둥이자리반·게자리반, 김하윤·이서준… | "2반 서준" | 예시를 **양자리반 이서준**으로 바꿨어요. 시연 화면도 같은 반·별님 데이터를 써요 |
| 6 | 반 측정 권한 | 담당 반만 입력 가능, 관리자가 다른 반 권한 부여 | 생활관 선생님 재측정 권한만 적음 | 생활관 선생님의 재측정·경고 시트도 **퀵 체온의 반 측정 권한을 그대로 따라요**. 권한 없는 반의 이상 건은 보기만 할 수 있어요 |
| 7 | 체온 저장 형식 | 정수로 저장 (365 = 36.5℃) | 소수 (38.4) | 8장 데이터 구조를 **정수(×10)**로 바꿨어요 (`firstTemp: 384`) |
| 8 | 저장 실패 | 입력값 유지 + 재시도 | 오프라인 시 나중에 보냄 | 이상 건은 **서버 저장이 성공한 뒤에만** 만들어요. 저장 실패 상태에서는 S1을 띄우지 않고 퀵 체온의 재시도 화면을 따라요 |

> 퀵 체온 담당에게 전달할 것: 퀵 체온 명세 1장에 "‘별님’은 돌봄 대상 **아동**"으로 적혀 있어요. 혜진원은 성인 거주인도 계신 **중증장애인 거주시설**이라 "거주인"으로 고치면 좋겠어요. 시제품의 일정 예시 "09:00 등원"도 거주시설과 맞지 않아요.

## 2. 용어

| 용어             | 뜻                                                                    |

## 4. 전체 흐름

```
[생활관] 퀵 체온: 다이얼로 조절 → 0.5초 눌러 기록 → 초록 "기록 완료"
   │  판정 = 주의 ──▶ 재측정 안내만 (이상 건 안 만듦) ─▶ 재측정도 주의 이상이면 ↓
   │  판정 = 이상 / 위험 / 저온
   ▼
(자동) 이상 건 생성  +  알림 발송  +  현황판 맨 위에 표시
   │
   ├─[생활관] 경고 시트: [투약 지침 보기] [간호사에게 전화] [30분 뒤 다시 재기]
   │
   ▼
[간호사·사무국·당직] 알림 받음 ──(N분 동안 확인 없음)──▶ (자동) 다음 사람에게 재알림
   │
   ▼  [확인했어요]  →  [제가 맡을게요]
   │
   ▼
대응 단계 (담당자가 진행, 단계마다 기록)
   ① 관찰·재측정 ─▶ ② 원내 조제 ─▶ ③ 원장 처방 ─▶ ④ 인근 병원
        ▲                 │               │               │
        └── 재측정 (30분 뒤 알림) ◀────────┴───────────────┘
   │
   ▼  체온이 평소로 돌아옴 / 병원 진료 / 입원 / 오측정
[대응 종료] ──▶ 별님 카드의 대응 이력에 영구 보관 (엑셀로 내보내기 가능)
```

### 이상 건의 상태

| 상태 | 뜻 | 다음 상태 |
|---|---|---|
| `미확인` | 생성 직후. 아무도 확인 안 함 | 확인됨 |
| `확인됨` | 1명 이상 확인. 담당자 없음 | 대응 중 |
| `대응 중` | 담당자 있음. 현재 대응 단계 ①~④ 중 하나 | 재측정 대기, 종료 |
| `재측정 대기` | 재측정 알림 시간을 기다리는 중 | 대응 중 (재측정 입력 시) |
| `종료` | 닫힘. 더 이상 알림 없음 | (다시 열기 시) 대응 중 |

## 6. 화면별 버튼·행동 명세

> 표 읽는 법
> - **ID**: 개발할 때 부를 이름 (예: `B-S3-02`)
> - **보이는 조건**: 이 버튼이 화면에 나타나는 때
> - **누르면**: 화면에서 일어나는 일
> - **남는 기록**: 이벤트 로그에 저장되는 내용 (8장의 `type` 값)
> - 기록에는 항상 **누가(사용자, 역할) · 언제(시각, 초 단위)**가 자동으로 들어가요. 표에는 그 외 내용만 적었어요.

### S1. 이상 경고 시트 (생활관)

생활관 선생님은 **두 손이 바빠요.** 그래서 버튼은 **크게, 3개 이하**로 두고 글은 두 줄 이내로 써요.

**뜨는 때**: 퀵 체온에서 0.5초 눌러 기록 → 서버 저장 성공 → 초록 "기록 완료"가 보인 직후(약 0.6초 뒤), 판정이 이상·위험·저온이면 시트가 아래에서 올라와요. 진동도 기록 완료와 다르게 **길게 2번** 울려요.

**자동으로 일어나는 일 (시트가 뜨는 순간)**
1. 이상 건 생성: 상태 `미확인`, 대응 단계 ①
2. 알림 발송 (7장 규칙)
3. 현황판 맨 위에 표시
4. 기록: `case_created` (체온값, 기저치, 차이, 판정 단계, 입력자)

**화면 내용**
- 큰 글씨: **"이서준 별님 38.4℃ · 평소보다 +1.3℃"**
- 판정 색 띠: 이상(주황) / 위험(빨강) / 저온(파랑)
- 안내 한 줄: "간호사·사무국에 알렸어요" (위험이면 "**원장님께도** 알렸어요")
- 알림 상태: "아직 아무도 확인 안 함" → 누군가 확인하면 실시간으로 "**박소연 선생님이 확인했어요 (2분 전)**"으로 바뀜

| ID | 버튼 | 보이는 조건 | 누르면 | 남는 기록 |
|---|---|---|---|---|
| B-S1-01 | **투약 지침 보기** | 항상 | S4 시트 열기 | `guideline_viewed` |
| B-S1-02 | **간호사에게 전화** | 항상 (야간에는 "당직 간호사에게 전화") | 휴대폰 전화 앱으로 연결 (`tel:` 링크). 돌아오면 "통화됐나요?" [네] [안 받음] 작은 질문 | `call_attempted` (받는 사람), 이어서 `call_result` (연결됨/안 받음) |
| B-S1-03 | **30분 뒤 다시 재기** | 항상 | 재측정 알림 예약. 상태 `재측정 대기`. 시트 닫힘. 토스트 "10:41에 다시 알려드릴게요" | `remeasure_scheduled` (예정 시각) |
| B-S1-04 | **잘못 쟀어요** (작은 글씨 링크) | 항상 | "잘못 잰 값으로 표시할까요? 알림도 취소돼요" 확인창 → [네] 누르면 이상 건 종료 (사유: 오측정), 알림 받은 사람들에게 "취소됨" 알림 | `case_closed` (사유 `mis_measure`) |
| B-S1-05 | 닫기 (✕) | 항상 | 시트만 닫힘. 이상 건은 그대로 진행 | 없음 (화면 닫기는 기록 안 함) |

> **위험(39.0℃↑ 등)일 때**는 B-S1-02 버튼을 **맨 위, 빨간색**으로 둬요.
> **[시연]** 전화는 실제로 걸지 않고 "박소연 선생님(010-0000-0000)에게 전화 연결" 토스트로 대신해요.

### S3. 이상 건 상세 (대응 카드) — 핵심 화면

**화면 구성 (위에서 아래로)**
1. **머리**: 별님 이름·반, 판정 색, 상태 칩(`미확인`/`확인됨`/`대응 중`/`재측정 대기`/`종료`), 경과 시간("12분 전 시작")
2. **체온 요약**: 처음 값 → 최근 값, 기저치, 차이. 재측정 값이 있으면 작은 꺾은선(최대 6점)
3. **대응 경로 진행 바**: ① 관찰·재측정 ─ ② 원내 조제 ─ ③ 원장 처방 ─ ④ 인근 병원 (현재 단계 진하게, 지난 단계 체크)
4. **확인한 사람**: 아바타 + 이름 + 시각 ("박소연 10:13 · 이민재 10:15")
5. **담당자**: 이름 또는 "아직 없음"
6. **별님 참고 정보** (접힘/펼침): 장애 특성, 주요 병력, 복용 약, 알레르기 (F1에서 가져옴)
7. **대응 기록 타임라인**: 모든 기록을 시간순으로 (8장)
8. **행동 버튼 영역** (하단 고정)

### S4. 투약 지침 보기 시트

**원칙: 앱은 투약 지침을 "보여주기만" 해요.** 지침은 F1 별님 프로필에서 간호사·원장님이 미리 써둔 글이에요. 앱이 체온이나 체중으로 용량을 계산하지 않아요.

**화면 내용**
- 제목: "이서준 별님 투약 지침"
- **작성자·마지막 수정일**: "박소연 간호사 작성 · 2026-10-30 수정 · 원장 확인 ✅"
- 지침 본문 (작성된 그대로). 예:
  > 38.5℃ 이상이고 처지면 아세트아미노펜 시럽 ○ml. 투약 전 반드시 간호사(야간: 010-…)에게 전화. 6시간 안에 다시 주지 않기. 39.5℃ 이상 또는 경련 시 바로 원장님께 연락.
- 체중·알레르기·복용 약 (F1에서 가져와 함께 표시)
- **최근 투약 기록**: "오늘 10:20 아세트아미노펜 ○ml (박소연)" — 중복 투약 방지용
- 아래 고정 문구: "이 지침은 의료진이 미리 작성한 것이에요. 판단이 어려우면 간호사·원장님께 먼저 연락하세요."

| ID | 버튼 | 보이는 조건 | 누르면 | 남는 기록 |
|---|---|---|---|---|
| B-S4-01 | **투약했어요** | 이상 건에서 연 경우 + 투약 기록 권한 있음 (3장) | 투약 기록 입력: 약 이름(지침에 있는 약 버튼 + 직접 입력), 용량(직접 입력), 시각(기본값 지금), 지시한 사람(선택) → 저장. 대응 단계가 ①이면 "② 원내 조제로 올릴까요?" 함께 묻기 | `medication_given` (약, 용량, 시각, 지시자) |
| B-S4-02 | **간호사에게 전화** | 항상 | 전화 연결 | `call_attempted`, `call_result` |
| B-S4-03 | 닫기 | 항상 | 시트 닫기 | 없음 |

**지침이 없을 때**
- 문구: "**등록된 투약 지침이 없어요.** 간호사·원장님께 먼저 연락하세요."
- 버튼: [간호사에게 전화] [원장님께 전화]
- 사무국·간호사에게 "이서준 별님 투약 지침이 비어 있어요" 할 일 알림 1회 (같은 별님은 하루 1회까지)

**지침이 오래됐을 때** (마지막 수정 후 180일 이상 **[초안]**)
- 노란 띠: "6개월 넘게 수정되지 않은 지침이에요. 체중이 바뀌었을 수 있어요."

> **[확인 필요]** 6시간 투약 간격 같은 숫자는 앱이 정하지 않아요. 지침에 써 있는 대로만 보여줘요. 다만 "같은 약을 최근 N시간 안에 기록한 적이 있으면 경고"를 넣을지는 간호사 선생님께 여쭤봐요.

### S5. 단계 올리기 시트

단계는 **기존 혜진원 대응 경로**와 똑같이 둬요. 단계를 건너뛸 수 있어요 (예: ①에서 바로 ④ 병원).

| 단계 | 시트 제목 | 입력 항목 | 알림 보낼 사람 |
|---|---|---|---|
| ② 원내 조제 | "원내 조제로 대응할까요?" | 약 이름, 용량, 투약 시각 (S4의 투약 기록과 같음), 지시자 | 간호사 (본인이 아니면), 사무국 |
| ③ 원장 처방 | "원장님 처방을 요청할까요?" | 요청 이유 (빠른 선택: 열이 안 내림 / 증상 악화 / 합병증 의심 / 기타) + 메모 | **원장님** (+ 간호사, 사무국) |
| ④ 인근 병원 | "병원으로 이동할까요?" | 병원 이름 (자주 가는 병원 버튼 **[확인 필요]**), 이동 방법 (시설 차량 / 구급차 / 보호자), 동행자 | 원장님, 간호사, 사무국, **담임** |

| ID | 버튼 | 보이는 조건 | 누르면 | 남는 기록 |
|---|---|---|---|---|

### S6. 재측정 입력

새 화면을 만들지 않고 **퀵 체온 화면을 그대로** 열어요. 다른 점은 세 가지예요.
- 그 별님의 반·별님이 **이미 선택된 채로** 열려요. 다이얼 시작값은 36.5℃가 아니라 **이 이상 건의 마지막 체온**이에요.
- 큰 이름 위 작은 줄(`양자리반 · 2 / 5` 자리)에 **"재측정 · 이상 건 진행 중 · 직전 38.4℃"**를 표시해요.
- 0.5초 눌러 기록하면 퀵 체온의 초록 "기록 완료" 뒤에 S1 대신 **재측정 결과 시트**(아래 표)가 올라와요.

| ID | 버튼 | 보이는 조건 | 누르면 | 남는 기록 |
|---|---|---|---|---|
| B-S6-01 | 다이얼 **0.5초 눌러 기록** (퀵 체온과 같음) | 항상 | 새 체온 기록 저장 (퀵 체온 기록에도 남음) + 이상 건에 재측정 값 연결 → 결과 시트 | `remeasured` (값, 이전 값과 차이, 판정 단계) |
| B-S6-02 | 재측정 알림에서 **지금 재기** | 재측정 알림 도착 시 | S6 열기 | `notification_opened` |
| B-S6-03 | 재측정 알림에서 **10분 뒤에** | 재측정 알림 도착 시 | 10분 뒤 다시 알림 | `remeasure_snoozed` |

**저장 후 결과에 따라 앱이 제안하는 것** (제안만 하고, 사람이 버튼을 눌러야 실행돼요)

| 재측정 결과 | 화면 문구 | 제안 버튼 |
|---|---|---|
| 평소 범위로 돌아옴 | "평소 체온으로 돌아왔어요 (+0.2℃)" | [한 번 더 재고 종료하기] (30분 뒤 예약) · [지금 종료하기] → S7 |
| 내려갔지만 아직 이상 | "내려가고 있어요 (38.4 → 37.9℃)" | [30분 뒤 다시 재기] |
| 그대로 | "변화가 없어요" | [30분 뒤 다시 재기] · [다음 단계로] |
| 올라감 / 위험으로 바뀜 | "**올라갔어요** (38.4 → 39.1℃)" + 빨간 띠 | [다음 단계로] (강조) · [간호사에게 전화]. **위험으로 바뀌면 원장님께 자동 알림** |

- 재측정 결과는 담당자, 그리고 이 건을 확인한 사람 모두에게 알림으로 가요 (S2의 "재측정 결과").
- 재측정 알림이 왔는데 **20분 안에 아무도 재지 않으면** **[초안]** 담당자에게 "재측정이 아직 안 됐어요" 알림을 한 번 더 보내요. 기록: `remeasure_missed`

| `event_voided` | (원래 줄에 취소선 + "박소연 취소: 잘못 누름") |

### 엑셀 내보내기 (F6에 넘길 항목)
- **이상 건 시트**: 한 건 = 한 줄 (별님, 반, 시작 시각, 처음/최고/마지막 체온, 기저치, 최고 단계, 담당자, 첫 확인까지 걸린 시간, 종료 사유, 총 걸린 시간)
- **대응 기록 시트**: 기록 한 줄 = 한 줄 (취소된 기록도 "취소됨" 표시로 포함)
- 이 두 시트로 01번 문서 8장의 **이상 전달 시간**과 **대응 기록률**을 바로 계산할 수 있어요.

## 9. 예외 상황

| 상황 | 앱 동작 |
|---|---|
| 두 사람이 거의 동시에 [제가 맡을게요] | 먼저 저장된 사람이 담당. 늦은 사람에게 "박소연 선생님이 이미 맡았어요" + [확인만 하기] |
| 같은 별님에게 이상 건이 진행 중인데 또 이상 체온 입력 | 새 건을 만들지 않고 진행 중인 건에 `remeasured`로 붙임 (A-01) |
| 이상 건이 종료된 지 1시간 안에 다시 이상 **[초안]** | 새 건을 만들고 "1시간 전에 종료된 건이 있어요" 링크 표시 |
| 숫자를 잘못 눌러 이상 건이 생김 (예: 36.8을 38.6으로) | 입력자가 S1의 [잘못 쟀어요] 또는 S7의 오측정 종료. 알림 받은 사람에게 취소 알림 |
| 인터넷이 끊김 | 버튼 기록은 기기에 잠시 저장했다가 연결되면 보냄. 화면 위에 "오프라인 · 연결되면 보낼게요" 띠. 알림이 못 갔을 수 있으니 **"간호사에게 전화" 버튼을 강조** |
| 야간에 아무도 확인 안 함 (에스컬레이션 끝까지) | 마지막 단계에서 생활관 화면에 "아직 아무도 확인하지 않았어요. **원장님께 직접 전화**하세요" + 전화 버튼 |
| 투약 지침 없음 / 오래됨 | S4 참고 |
| 담당자가 퇴근 | A-08 교대 인계. 담당자는 그대로 두고 야간 당직에게 알림. 필요하면 [담당 넘기기] |
| 권한 없는 버튼 | 숨기지 않고 흐리게 + 누르면 "간호사·원장님만 기록할 수 있어요" (무엇이 가능한지 알 수 있게) |

## 10. 화면 문구 원칙

- **짧게**: 생활관 화면은 두 줄 이내.
- **판단 대신 안내**: "열이 있습니다" ❌ → "평소보다 +1.3℃ 높아요" ✅
- **행동 동사로 버튼 이름**: "확인" ❌ → "확인했어요" ✅, "다음" ❌ → "원장 처방 요청" ✅
- **진단·처방 표현 금지**: "해열제를 주세요", "감기예요" 같은 말은 앱이 하지 않아요. 지침 원문을 보여줄 때만 예외.
- **사람 이름 + 선생님**: "박소연 선생님이 확인했어요".
- 색만으로 구분하지 않기: 색 + 아이콘 + 글자 (색약 선생님 배려).

## 11. 금요일 시연 범위

| 기능 | 시연에서 | 나중에 |
|---|---|---|
| 역할 | 화면 위 **역할 바꾸기 버튼** (생활관/사무국/간호사/원장) | 로그인·계정 |
| 데이터 저장 | 브라우저 안 로컬 저장 + 가짜 별님 데이터 | 서버 (운영진 답변 후) |
| 알림 | 앱 안 배너 + 소리 + 🔔 배지 | 실제 푸시 알림 |
| 전화 | 토스트로 대신 | 실제 `tel:` 연결 |
| 에스컬레이션 | **시간을 빠르게** (15분 → 15초) 하는 "시연 모드" 스위치 | 실제 시간 |
| 주간/야간 | 화면의 [주간]/[야간] 스위치 | 실제 시계 |
| 엑셀 내보내기 | (F6 담당과 맞춰서) | |

> 시연 화면 파일: `별자리노트_이상대응_전달용/별자리노트_이상대응_화면시제품.html`. 팀원 퀵 체온 시제품을 그대로 쓰고 그 위에 이상 대응을 얹었어요. 왼쪽 조작판에서 역할·야간·시연 모드를 바꾸고, 아래 순서가 자동으로 체크돼요. 주소 뒤에 `?shot=1`(경고 시트) · `?shot=2`(간호사 대응 카드) · `?shot=3`(사무국 현황판)을 붙이면 그 장면으로 바로 가요.

**시연 시나리오 (3분)** — 이 순서대로 되면 성공
1. [생활관] 퀵 체온에서 양자리반 이서준 별님 선택 → 다이얼로 38.4℃ → 0.5초 눌러 기록 → 초록 "기록 완료" → S1 경고 시트 "평소보다 +1.3℃", "간호사·사무국에 알렸어요"
2. [생활관] [투약 지침 보기] → 미리 써둔 지침 확인 → 닫기 → [30분 뒤 다시 재기]
3. [간호사]로 역할 바꾸기 → 알림 배너 → [확인했어요] → [제가 맡을게요]
4. [생활관]으로 돌아가면 S1에 "박소연 선생님이 확인했어요"가 보임
5. [간호사] [조치 기록 추가] 💧 수분 섭취 → [다음 단계로] ② 원내 조제 → 투약 기록
6. (시연 모드) 재측정 알림 → 39.1℃ 입력 → "올라갔어요" + 원장님 자동 알림
7. [원장]으로 바꾸기 → [병원으로 보내세요] → 단계 ④
8. [사무국] 현황판 맨 위에 진행 중인 건과 타임라인 전체가 보임
9. [간호사] [병원 도착] → [진료 결과: 귀원] → [대응 종료: 병원 진료 후 귀원]
10. 별님 카드 → [대응 이력]에 오늘 건이 남아 있음

## 12. 완료 체크리스트 (개발 후 확인용)

- [ ] 이상·위험·저온 판정 시 이상 건이 자동 생성되고, 주의·평소는 생성되지 않는다
- [x] 같은 별님에게 진행 중인 건이 있으면 새 건이 생기지 않고 재측정으로 붙는다
- [ ] 6장의 모든 버튼이 표에 적힌 조건에서만 보인다
- [ ] 버튼을 누를 때마다 8장 `type`에 맞는 기록이 1줄 남고, 누가·언제가 들어간다
- [ ] 기록은 삭제되지 않고, 취소하면 `event_voided`가 추가되며 원래 줄에 취소선이 생긴다
- [ ] 확인/담당/단계/재측정/종료가 다른 역할 화면에 바로(새로고침 없이) 반영된다
- [ ] 투약 지침은 원문 그대로만 보이고, 앱이 용량을 계산하는 곳이 없다
- [ ] 시연 모드에서 에스컬레이션이 동작한다 (15초 뒤 다음 사람에게 재알림)
- [ ] 11장 시연 시나리오 10단계가 끊김 없이 된다
- [ ] 폰 화면(375px)과 PC 화면 둘 다 깨지지 않는다
- [ ] 퀵 체온의 초록 "기록 완료"가 먼저 보이고, 그 뒤에 S1이 올라온다 (저장 실패 시 S1이 뜨지 않는다)
- [ ] 재측정은 퀵 체온 화면이 해당 반·별님, 직전 체온으로 선택된 채 열린다

**혜진원 (간호사·원장님)**
1. 야간에 간호사가 없을 때 **당직 선생님이 투약 지침대로 해열제를 줄 수 있나요?** 아니면 간호사 전화 지시가 꼭 필요한가요?

3. 단계 ②→③→④로 넘어가는 기준이 있나요? (몇 시간 지나도 안 내리면, 몇 도 이상이면 등)

6. 조치 칩(수분, 옷, 미온수 등) 목록이 현장과 맞나요?
7. 주간·야간 근무가 바뀌는 시각

**팀 회의**

2. 기록 취소 가능 시간 10분, 다시 열기 가능 시간 24시간이 적당한지
