# 별자리노트 | 사무국 PC 웹 기능명세 v1.0

사무국 담당자는 **오늘 어느 별님의 상태를 먼저 살펴봐야 하는지** 확인하고, 해당 별님의 최근 체온·평소 기록·대응 이력을 한 화면에서 비교할 수 있다. 첫 화면은 **오늘 현황**이다.

## 1. 메뉴와 구현 범위

| 메뉴 | 사무국에서 하는 일 | 우선순위 |
|---|---|---|
| 오늘 현황 | 반별 측정 현황과 현재 대응 중인 별님 확인 | 필수 |
| 별님 기록 | 반·별님 선택, 체온 추이와 관찰 기록 검색, 원본 상세 열람 | 필수 |
| 이상 대응 현황 | 진행 중인 건의 담당자·마지막 조치 확인, 종료 이력 조회 | 필수 |
| 반별 일정 / 전체 시간표 | 선택한 반의 하루 일정, 시간대별 전체 일정 조회 | 후속 |
| 일정 파일 가져오기 / 기록 내보내기 | 일정표 미리보기와 반영, 허용된 조회 결과의 파일 출력 | 후속 |

왼쪽 메뉴를 고정하고 오른쪽에서 조회한다. 반·날짜를 선택하면 표 위에 현재 조건과 마지막 갱신 시각을 표시한다. 다른 메뉴에서 특정 별님이나 대응 건으로 이동할 때는 대상이 미리 선택되어야 한다.

## 2. 오늘 현황

- **기본값:** 기관 현지 날짜의 오늘, 열람 가능한 전체 반. 상단에 ‘오늘 체온 기록 있음’, ‘오늘 체온 기록 없음’, ‘현재 대응 중’을 표시한다. 앞의 두 숫자는 **별님 수**, 마지막 숫자는 **대응 건수**로 단위를 붙인다.
- **집계:** 같은 별님의 체온을 세 번 기록해도 ‘기록 있음’은 한 명이다. ‘기록 없음’은 오늘 측정값이 없다는 뜻이며 측정 누락이나 건강 이상으로 판정하지 않는다. 어제 시작해 아직 종료되지 않은 대응 건은 ‘현재 대응 중’에 포함한다.
- **반별 표:** 반 이름, 소속 인원, 오늘 체온 기록 인원, 마지막 측정 시각, 진행 중인 대응 건수. 반 이름을 누르면 화면 아래 별님 목록이 해당 반으로 좁혀진다.
- **먼저 살펴볼 별님:** 열린 대응 건과 공통 판정에서 확인이 필요한 측정 기록을 보여준다. 같은 별님의 같은 측정에 대응 건이 연결돼 있으면 한 행으로 합친다. 행에는 이름·반, 최근 체온과 측정 시각, 개인 기준 체온(제공 시), 원본 판정 문구, 대응 상태를 표시한다. 이름은 별님 기록으로, 대응 상태는 해당 건 상세로 연결한다.
- **갱신:** 새 기록이 도착하면 해당 행과 집계를 갱신하되 담당자가 보고 있는 상세를 닫거나 선택 대상을 바꾸지 않는다. 갱신에 실패하면 기존 값에 ‘마지막 확인 HH:MM’을 표시하고 ‘다시 불러오기’를 제공한다.

## 3. 별님 기록 아카이브

| 동작 | 화면 결과 |
|---|---|
| 반 선택 → 별님 이름 검색 → 별님 선택 | 왼쪽 목록에는 이름과 반을 함께 표시하고, 오른쪽에는 선택한 별님의 현재 반·담임, 마지막 체온·측정 시각, 체온 추이, 기록 타임라인을 표시한다. 동명이인은 별님 ID로 구분한다. |
| 체온 추이 조회 | 기본 최근 7일. 측정 시각별 실제 값을 표시하고 표로도 볼 수 있다. 측정하지 않은 날은 비워 둔다. 개인 기준 체온이 없으면 ‘기준 미등록’으로 표시하며 웹에서 임의 기준이나 판정값을 만들지 않는다. |
| 타임라인 범위 선택 | 기본 ‘모두’. ‘이 별님 기록’에는 체온·관찰 등 개인 기록을, ‘반 공지’에는 공지 당시 해당 반에 속한 별님에게 적용되는 공지를 표시한다. 시설 전체 공지는 개인 기록 건수에서 제외한다. |
| 기간·검색어 적용 | 타임라인 기본 기간은 전체. 최근 7일·최근 30일·직접 지정 가능. 본문·기록자 부분 일치를 기간과 함께 적용한다. 검색 결과 건수와 별님의 누적 기록 수를 구분한다. |
| 기록 한 건 열기 | 상세 패널에 대상, 발생 일시, 당시 기록자, 출처, 본문, 연결된 대응 건을 표시한다. 닫으면 검색 조건·선택 행·스크롤 위치가 유지된다. 단순 열람은 업무 확인이나 대응 종료로 처리하지 않는다. |
| 이전 담임 기록 조회 | 담당자가 바뀌어도 개인 기록을 유지한다. 타임라인에 담임 변경 시점을 구분선으로 표시하고 각 기록에는 당시 작성자를 표시한다. |

타임라인은 최신 발생 시각순이다. 체온은 측정 시각을 사용한다. 동일 측정이 인수인계와 체온 기록 양쪽에서 참조되더라도 측정 ID 기준 한 건으로 표시한다. **재측정**은 새 측정으로 추가하고 **정정**은 기존 측정에 반영한다. 반 공지도 원본 한 건을 참조하므로 별님마다 별도 사본을 만들지 않는다.

## 4. 이상 대응 현황

- 기본 탭은 **진행 중**이다. ‘종료’ 탭에서는 종료 일자·반·별님으로 이력을 좁힌다. 기본 표시는 발생 시각, 별님·반, 최초 측정값, 마지막 조치와 시각, 담당자, 현재 단계다. 담당자가 없으면 ‘미지정’, 아직 조치가 없으면 ‘조치 기록 없음’으로 표시한다.
- 행을 누르면 **발생 → 확인 → 담당 지정 → 조치 → 종료** 중 실제로 남아 있는 사건을 시각순으로 표시한다. ‘최초 측정 보기’는 해당 측정 한 건으로, ‘별님 기록 보기’는 해당 별님 타임라인으로 이동한다.
- 웹 초안의 대응 화면은 **조회용**이다. 화면을 열거나 닫아도 알림 확인·담당 지정·업무 완료·종료 상태는 바뀌지 않는다. 종료가 기록되면 진행 중 목록에서 빠지고 종료 이력에 남는다. 이후 체온 수치만으로 웹이 대응 건을 자동 종료하지 않는다.

## 5. 일정 조회와 파일 기능 — 후속

- **일정 조회:** ‘반별 일정’은 선택한 날짜·반의 별님별 하루 일정을, ‘전체 시간표’는 시간 × 별님 격자를 표시한다. 같은 일정 ID를 사용한다. 측정 예정 시점과 실제 측정 기록은 문구로 구분한다.
- **일정 가져오기:** 파일 선택 → 행별 미리보기 → 오류 수정 또는 제외 → 반영. 초기 지원 형식은 열 정의가 있는 XLSX로 제안한다. 필수 열은 날짜·반·대상·시작·종료·일정명이다. 별님 이름이 중복되면 대상을 직접 선택하게 한다. 유효하지 않은 날짜, 종료가 시작보다 이른 행, 중복 일정을 표시하고 반영 전에는 기존 시간표를 변경하지 않는다. 반영 후 성공·제외 건수를 표시한다. HWPX 자동 변환은 지원이 확정되기 전까지 제공하지 않는다.
- **건강 기록 내보내기:** 권한이 있는 담당자에게만 제공한다. 현재 반·별님·기간으로 범위를 제한하고, 내보낼 항목과 건수를 먼저 보여준다. 초기 형식은 엑셀에서 열 수 있는 CSV로 제안한다. 기본 열은 반·별님·측정 시각·체온·원본 판정이다. 관찰 메모·병력 등은 기본 출력에서 제외한다.

## 6. 권한·오류·화면 상태

| 상황 | 처리 |
|---|---|
| 조회 권한 제한 | 담당자에게 허용된 기관·반·별님 범위를 목록, 집계, 검색, 상세, 출력에 동일하게 적용한다. 상세 주소로 직접 접근해도 같은 권한을 검사한다. |
| 값 없음 | 체온 없음은 ‘기록 없음’, 기준 체온 없음은 ‘기준 미등록’, 검색 0건은 ‘조건에 맞는 기록이 없어요’로 구분한다. 빈 값을 0°C나 정상으로 표시하지 않는다. |
| 조회 중 반 변경 | 이전 반의 상세를 비우고 새 반을 불러온다. 늦게 도착한 이전 반 응답은 화면에 적용하지 않는다. |
| 연결 또는 권한 상실 | 연결 실패는 조회 실패와 재시도를 표시한다. 권한 상실 시에는 기존 기록도 즉시 가리고 상세·내보내기를 차단한다. |
| 공용 PC 이용 종료 | 로그아웃하면 화면에 남은 별님 상세·검색 결과를 지운다. 다른 계정으로 로그인해도 이전 계정의 마지막 조회 화면을 복원하지 않는다. |
| 키보드 조작 | 메뉴·검색·표의 상세 버튼은 키보드로 접근한다. Esc로 상세를 닫으면 원래 행으로 초점을 돌린다. 상태는 색과 함께 글자로 표시한다. |

## 7. 필수 기능 완료 기준

1. 한 별님의 측정값 두 건이 오늘 저장되면 반별 ‘기록 있음’ 인원은 한 명, 별님 타임라인의 측정 기록은 두 건이다.
2. 어제 시작된 미종료 건이 오늘 현황에 보인다. 해당 행에서 담당자와 마지막 조치를 열람해도 확인·종료 상태는 변하지 않는다.
3. 오늘 현황에서 별님을 누르면 정확히 그 사람의 기록이 열린다. 담임 변경 전 기록을 검색하면 당시 기록자 이름이 보인다.
4. 반 공지와 개인 관찰을 각각 필터링했을 때 같은 공지가 개인 기록으로 중복되지 않는다. 검색 조건을 지우면 원래 목록이 복원된다.
5. 새 측정이나 대응 종료가 반영되면 요약 숫자와 상세가 일치한다. 갱신 실패 시 ‘대응 0건’ 또는 ‘이상 없음’으로 바뀌지 않는다.
6. 열람할 수 없는 반은 집계와 검색에 포함되지 않고, 해당 상세 주소로도 접근할 수 없다.
