# 별자리노트 — 퀵 체온 입력 기능

기능 담당 범위: 퀵 체온 입력 화면과 조작, 체온 기록 연결

기준일: 2026-11-11

이 문서는 전체 앱 명세를 취합할 때 사용하는 기능 설명 자료다. 별도의 AI 작업 지시나 독립 앱 개발 프롬프트가 아니다. 기술 스택·공통 데이터 모델·API·디자인 시스템은 전체 앱 통합 설계에서 결정되며, 아래는 해당 구조 안에서 유지되는 기능의 동작이다.

## 1. 목적과 범위

선생님이 체온계에서 확인한 별님의 체온을 앱에서 빠르게 입력하고 기록하는 기능이다. ‘별님’은 돌봄 대상 아동이다. 휴대전화 자체의 체온 측정이나 체온계 기기 연동은 포함하지 않는다.

기존 인수인계·일정 탭 사이의 중앙 퀵 버튼으로 접근한다. 담당 범위는 퀵 체온 화면, 반·별님 선택, 체온 입력, 기록 요청과 결과 표시다. 전체 앱의 다른 기능을 대체하지 않는다.

## 2. 진입과 접기

- 중앙 퀵 버튼을 누르면 별도 전체 화면 레이어가 펼쳐진다.
- 하단의 인수인계·퀵 체온·일정 메뉴와 중앙 버튼은 같은 자리를 유지한다.
- 버튼을 다시 누르면 화면이 중앙 버튼 안으로 들어가듯 접힌다.
- 다시 펼치면 선택한 반·별님과 작성 중인 체온이 유지된다.
- 접기 자체로는 기록이 저장되지 않는다. 다시 펼칠 때는 별님 선택 모드로 복귀한다.
- 반 선택 모드 진입은 새 페이지 전환과 구분된다. 반 선택은 아래와 같이 동일 화면 안에서 이루어진다.

시제품은 화면 확인을 위해 퀵 체온이 열린 상태로 시작한다. 실제 앱의 시작 화면은 전체 앱 흐름에 따른다.

## 3. 화면 구성과 기본값

상단부터 반 선택 탭, 별님 프로필 목록, 선택한 별님의 큰 이름, 디지털 체온 숫자, 원형 다이얼, 보조 ± 버튼, 제스처 안내 순서다.

- 기본 반: 로그인한 선생님의 담당 반.
- 기본 별님: 해당 반 목록의 첫 번째 별님.
- 최초 입력 체온: 36.5℃.
- 별님 목록: 작은 원형 프로필과 이름으로 약 5명이 가로로 나열된다. 실제 인원과 순서는 앱 데이터에 따른다.
- 배경: 선택한 별님의 프로필을 전체 화면으로 확대하고 밝은 오버레이를 적용한다.
- 큰 이름과 디지털 체온 숫자는 같은 시각적 크기다. 시제품은 이름 글자 크기 43px, 체온 숫자 높이 43px다.
- 체온의 디지털 모양은 유지하며 ℃는 보조 크기로 표시한다.
- 반 탭은 반투명 유리 질감의 둥근 캡슐 형태다.
- 반 이름은 별자리 이름을 사용한다. 시연 예시는 양자리반·황소자리반·쌍둥이자리반·게자리반이다.

이름·프로필·배경·체온·기록 상태는 항상 동일한 별님을 가리킨다.

## 4. 선택 테두리와 제스처

현재 조작 대상을 나타내는 선택 테두리는 하나다. 별님 선택 모드에서는 원형 프로필을, 반 선택 모드에서는 반 탭을 둘러싼다. 테두리는 위치와 크기, 둥글기를 함께 바꾸며 이동한다.

| 조작 | 결과 |
| --- | --- |
| 별님 선택 모드에서 좌우로 쓸기 | 같은 반의 이전·다음 별님 선택 |
| 위로 쓸기 | 선택 테두리가 프로필에서 현재 반 탭으로 이동, 반 선택 모드 진입 |
| 반 선택 모드에서 좌우로 쓸기 | 권한이 있는 이전·다음 반으로 이동 |
| 아래로 쓸기 | 현재 반을 유지하며 테두리가 선택된 별님 프로필로 이동, 별님 선택 모드 복귀 |
| 별님 프로필 직접 터치 | 해당 별님을 선택하고 별님 선택 모드로 복귀 |
| 별님 선택 모드에서 반 탭 직접 터치 | 해당 반과 첫 별님으로 즉시 이동 |
| 반 선택 모드에서 반 탭 직접 터치 | 해당 반과 첫 별님으로 즉시 이동하며 반 선택 모드는 유지 |

반 선택 모드에서 반을 넘기는 즉시 아래 별님 목록도 그 반으로 바뀐다. 그 반의 첫 별님이 선택되며 큰 이름·배경·체온도 함께 갱신된다. 아래로 쓸기는 이미 표시 중인 반의 별님 선택으로 돌아오는 동작이며 별도 확인 페이지는 없다.

별님·반 목록의 양 끝에서는 멈추며 자동 순환하지 않는다. 각 별님의 작성 중인 값과 기록 상태는 별도로 유지된다. 처음 선택하는 별님은 36.5℃로 시작한다.

다이얼 영역의 드래그는 온도 조절로, 그 밖의 화면 쓸기는 선택 이동으로 처리된다. 대각선 쓸기는 이동량이 큰 축 하나만 적용한다. 시제품의 쓸기 인식 기준은 48px이며 실제 기기에서 조정 가능한 값이다.

## 5. 반 측정 권한

기본적으로 담당 반만 활성화된다. 관리자가 다른 반의 체온 입력 권한을 부여하면 해당 반도 활성화된다. 권한 없는 반은 잠금으로 표시되며 터치와 스와이프 모두 선택할 수 없다.

사용자가 바꿀 수 있는 권한 스위치는 실제 기능에 포함되지 않는다. 시제품의 체크박스는 다른 반 조작을 체험하는 시연 장치다.

실제 기록 요청은 서버에서도 사용자·기관·반·별님 소속과 측정 권한을 검증한다. 권한이 취소된 반의 기록 요청은 거절되며 담당 반으로 복귀한다.

## 6. 원형 다이얼

다이얼은 체온 조절 장치이자 길게 눌러 기록하는 버튼이다. 시제품 지름은 210px다.

- 시계 방향 회전은 증가, 반시계 방향 회전은 감소다.
- 체온은 0.1℃ 단위로 바뀐다.
- 눈금과 표시점이 손가락의 회전 각도를 따라 연속적으로 실제 회전한다.
- 다이얼 중앙의 안내 글자는 정방향을 유지한다.
- 숫자는 0.1℃ 단위로 표시하지만 회전 자체는 부드럽게 이어진다.
- 세로 휠 피커를 사용하지 않는다.
- ± 버튼도 동일하게 0.1℃씩 조절한다.
- 내부 체온은 정수로 표현한다. 예: 365 = 36.5℃.

시제품 설정은 6° 회전당 0.1℃, 입력 범위 34.0~42.0℃다. 이 수치는 조정 가능한 시제품 설정이며 의료적 정상 범위가 아니다. 회전 감도와 햅틱은 실제 기기 검증 대상이다.

## 7. 0.5초 눌러 기록

확정 시간은 **0.5초**다.

- 다이얼을 정지 상태로 0.5초 누르면 현재 별님과 체온의 기록을 요청한다.
- 누르는 동안 원형 진행 표시가 채워진다.
- 0.5초 전에 손을 떼거나 회전을 시작하면 저장하지 않는다.
- 시제품 기준 8px 이상 이동, 포인터 취소, 반·별님 변경, 화면 접기, 앱 비활성화는 진행 중 누름을 취소한다.
- 반 선택 모드에서 다이얼 터치를 시작하면 현재 반의 별님 선택 모드로 복귀한 뒤 조작한다.
- 한 번의 누름은 한 건의 요청으로 처리되며 중복 기록을 방지한다.

실제 앱에서는 저장 중 상태를 표시하고 서버 성공 응답 후 배경을 초록색으로 바꾼다. 체크 표시와 ‘기록 완료’ 문구도 함께 표시한다. 초록색의 의미는 기록 완료이며 정상 체온 판정이 아니다.

저장 실패 시 입력값을 유지하고 재시도 상태를 제공한다. 기록 직후 다음 별님으로 자동 이동하지 않는다. 저장한 체온을 수정하면 완료 상태가 해제되고 다시 0.5초 눌러 기록한다.

## 8. 제스처 안내

단순 화살표 대신 손가락이 화면을 쓸어 움직이는 그림과 문구를 함께 사용한다.

- 별님 선택 모드: ‘별님 선택 중’, ‘별님 바꾸기’, ‘화면을 좌우로 쓸어 주세요’.
- 반 선택 모드: ‘반 선택 중’, ‘반 바꾸기’, ‘화면을 좌우로 쓸어 주세요’.
- 아래 두 안내는 항상 함께 표시된다: ‘위로 쓸어 반 바꾸기’, ‘아래로 쓸어 별님 선택’.
- 현재 모드에서 다음으로 전환하는 방향을 더 선명하게 강조한다.
- 위·아래 안내 영역을 직접 터치해도 같은 모드 전환이 가능하다.
- 동작 줄이기 설정에서는 손가락 안내 애니메이션이 정지한다.

## 9. 다른 기능과의 연결

| 공통 영역 | 필요한 연결 |
| --- | --- |
| 로그인 사용자 | 선생님 ID, 기관, 담당 반 |
| 반과 별님 관리 | 반 이름, 별님 ID·이름·프로필, 반별 목록과 순서 |
| 관리자 권한 | 다른 반 체온 입력 허용 범위와 권한 변경 |
| 체온 기록 저장 | 별님 ID, 반 ID, 체온, 측정 시각, 기록자, 서버 기록 시각 |
| 인수인계 | 저장된 체온 기록을 공통 기록 데이터에서 조회하는 연결 |
| 공통 하단 내비게이션 | 퀵 버튼 진입·접기와 기존 탭 이동 |

저장 데이터·API 이름·인증 방식은 전체 앱 구조에서 통합된다. 기록자와 기관은 인증된 서버 정보에 기반한다. 아동 소속·권한 검사, 저장 실패, 중복 요청 처리가 필요하다.

반을 빠르게 넘기는 경우 이전 반의 늦은 응답이 현재 목록을 덮어쓰지 않아야 한다. 목록 로딩·실패·빈 반·프로필 없음 상태에서도 이전 반의 별님을 현재 반 소속처럼 표시하지 않는다. 다른 반을 조회할 권한도 공통 권한 체계를 따른다.

새 재측정 기록과 기존 기록 정정의 구분, 오프라인 동기화, 앱 종료 후 초안 유지 정책은 전체 앱의 공통 정책 결정사항이다.

## 10. 시제품과 실제 앱의 구분

HTML은 화면과 조작 참고용이다. 실제 저장 서버·관리자 기능·체온계 연결은 없다. 입력은 브라우저 탭 메모리에만 있으며 새로고침하면 삭제된다. 시제품의 반별·별님별 마지막 기록 한 건 보관은 동작 확인용 단순화다.

프로필은 실제 아동이 아닌 가상 일러스트다. 실제 앱은 권한이 있는 프로필 데이터를 사용한다. 화면 전체를 PNG로 구현하는 방식이 아니라 텍스트·벡터 다이얼·이미지·애니메이션을 조합하는 화면이다.

실제 앱에서는 작은 화면과 safe area, 큰 글자 설정, 스크린 리더, 제스처 대체 조작을 지원한다. 이름·체온·기록 상태가 접근성 정보로 제공되며, 0.5초 누름이 어려운 사용자를 위한 대체 기록 동작은 공통 접근성 정책에 연결된다.

## 11. 완료 판단 기준

- 담당 반·첫 별님·36.5℃로 최초 진입한다.
- 권한 없는 반은 선택과 기록이 차단된다.
- 선택 테두리가 같은 화면 안에서 프로필과 반 탭 사이를 이동한다.
- 좌우 쓸기의 대상은 현재 모드에 맞게 반 또는 별님으로 구분된다.
- 반이 바뀌는 즉시 해당 반 목록·첫 별님·배경·체온이 일치한다.
- 다이얼이 손가락을 따라 회전하고 체온은 0.1℃씩 바뀐다.
- 이름과 체온 숫자는 같은 시각적 크기다.
- 0.5초 미만 누름과 회전·화면 이탈은 오기록을 만들지 않는다.
- 저장 성공 후 초록색 완료 상태가 나타나며 실패 시 입력을 유지한다.
- 접기·복원 시 선택과 초안이 유지된다.
- 제스처 안내와 하단 메뉴가 겹치지 않는다.

시제품은 브라우저에서 기본 선택, 권한 잠금·해제, 0.5초 누름, 회전, 반·별님 전환, 초안 유지, 접기·복원, 키보드 조절과 모바일 가로 넘침을 확인했다. 서버 권한·저장 실패·실제 기기 햅틱과 네이티브 접근성은 통합 앱 단계의 검증 항목이다.
