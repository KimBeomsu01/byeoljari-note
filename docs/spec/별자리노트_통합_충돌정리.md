## 🔴 충돌 — 결정이 필요한 것

### C1. 체온 판정 기준과 단계 이름 ⭐ 가장 중요
| 인수인계 | 이상 대응 · 일정 · 문제정의서(01) |
|---|---|
| **4단계, 고정 숫자만** | **5단계, 별님마다 다른 평소 체온(기저치) + 고정 숫자 안전장치** |
| 고온 ≥ 38.0 / 미열 37.0~37.9 / 정상 36.0~36.9 / 저온 < 36.0 | 평소 / 주의(+0.5 또는 37.5↑) / 이상(+1.0 또는 38.0↑) / 위험(+1.5 또는 39.0↑) / 저온(−1.0 또는 35.5↓) |

- 문제: 평소 37.1℃인 이서준 별님이 37.4℃면 인수인계는 "미열", 이상 대응은 "평소"예요. 화면마다 다른 말을 하게 돼요.
- **제안:** 5단계 하나로 통일해요. 피드백 1순위가 "별님별 기저치"였기 때문이에요. 인수인계 화면의 단계 이름과 색만 바꾸면 돼요.
- 숫자(0.5 / 1.0 / 1.5, 37.5 / 38.0 / 39.0 / 35.5)는 **간호사 선생님 확인 전까지 초안**이에요.

### C2. "긴급"과 "이상 건"이 따로 있음 ⭐
- 인수인계에는 자체 **긴급(Alert)** 이 있어요. 열림/해제 두 상태, 30분 재측정, 간호사 자동 알림 1단계.
- 이상 대응에는 **이상 건(Case)** 이 있어요. 미확인 → 확인됨 → 대응 중 → 재측정 대기 → 종료, 대응 단계 ①~④, 담당자, 재알림.
- 같은 사건을 두 번 저장하면 한쪽만 업데이트되는 버그가 생겨요.
- **제안:** 데이터는 **이상 건 하나만** 저장해요. 인수인계 맨 위 "긴급" 칸은 열린 이상 건을 **보여주는 창**이에요. 긴급 카드를 누르면 이상 건 상세로 가요.

### C3. 긴급은 언제 끝나나 ⭐
| 인수인계 | 이상 대응 |
|---|---|
| 재측정 값이 정상 범위면 **자동 해제** | **사람이 [대응 종료]를 눌러야** 끝남. 평소로 돌아오면 "한 번 더 재고 종료" / "지금 종료" 제안 |

- **제안 (둘 다 살림):** 재측정 값이 평소·주의로 내려오면 인수인계 **긴급 칸에서는 내려가요** (인수인계 의도 유지). 대신 이상 건은 **"종료 대기"** 상태로 열려 있다가 담당자가 종료해요 (기록 책임 유지). 🔔 와 사무국 현황판에는 종료 전까지 보여요.

### C4. 재측정은 어떤 화면에서 입력하나 ⭐
- 인수인계: **숫자패드 시트** (3·6·9 누르면 36.9)
- 퀵 체온: **원형 다이얼 + 0.5초 누르기**. 이상 대응도 다이얼로 맞추기로 정함
- **제안:** 체온 입력은 **퀵 체온 화면 하나로** 통일하고 숫자패드는 없애요. 다른 화면의 [재측정 입력] / [완료하기] / 일정의 "체온 측정" 줄은 **그 별님이 선택된 채로 퀵 체온을 열어요.**
  - 그래서 퀵 체온 명세의 "진입은 가운데 버튼만"을 "가운데 버튼 + 다른 화면에서 별님을 정해서 열기"로 바꿔야 해요 → **퀵 체온 담당 확인 필요**
  - 체온 재측정 할 일이 열린 별님을 퀵 체온으로 기록하면 그 할 일은 **자동 완료**돼요.
  - 체온이 아닌 할 일(메모)은 숫자 입력 없이 [완료] 확인만 받아요 (인수인계 TBD 정리).

### C5. 가상 명단(반·별님·선생님 이름)이 두 벌 ⭐
| 인수인계 · 아카이브 | 퀵 체온 · 일정 · 이상 대응 |
|---|---|
| 물병자리·물고기자리·곰자리·은하수자리·양자리·고래자리 (6반) | 양자리반·황소자리반·쌍둥이자리반·게자리반 (4반 × 5명) |
| 서준, 승민, 도윤, 나리, 현우 (이름만) | 김하윤, 이서준, 박지우 … (성+이름 20명) |
| 선생님: 김하늘·박지은·이수진·최민호 | 담임: 김하늘·오지민·이수진·박지은 / 간호사 박소연, 사무국 이민재, 원장 한경수 |

- **제안:** 이미 세 파트가 같이 쓰는 **4반 20명 명단**을 공통으로 써요. 인수인계·아카이브 시연 장면은 이름만 옮겨요 (예: 승민 38.2° → 쌍둥이자리반 **장도현 38.2°**. 일정에서 이미 "이상 대응 중"으로 나와요). 옮김표는 통합 명세 10장에 있어요.
- 아카이브 명세가 경고한 대로 "서준"과 "이서준"을 같은 사람으로 자동으로 합치지 않고, 통합 명단으로 **새로 만들어요.**

### C6. 같은 "확인"이 세 가지 뜻
| 어디 | 뜻 | 취소 |
|---|---|---|
| 인수인계 [확인] | 이 기록을 **읽었다** | 다시 누르면 취소 (토글) |
| 이상 대응 [확인했어요] | 이상 알림을 **받았고 내가 안다** → 재알림이 멈춤 | 취소 없음 (기록으로 남음) |
| 할 일 [완료하기] | 일을 **끝냈다** | — |

- **제안:** 저장도 버튼 글자도 따로 둬요. 긴급 카드의 확인 버튼은 [확인했어요]로 쓰고, 누르면 **이상 건 확인**으로 기록해요 (긴급은 원래 "안 본 기록" 숫자에서 빠지니까 겹치지 않아요).

### C7. 잘못 쟀거나 잘못 쓴 기록 고치기
- 아카이브: 정정은 **같은 측정 ID의 최신 버전**
- 이상 대응: **지우지 않고 "취소됨" 표시 + 새 기록**
- 인수인계: 수정은 허용하되 **이전 내용을 이력으로**
- 퀵 체온: "공통 정책으로 정하자"
- **제안:**
  - **체온 값은 고치지 않아요.** [잘못 쟀어요]로 "무효" 표시를 하고 새로 재요. 새 측정은 옛 측정을 가리켜요 (`correctsId`). 아카이브에는 옛 값이 취소선으로 보여요.
  - **메모(관찰 기록)는 고칠 수 있게** 하고 이전 글을 이력으로 남겨요.
  - 이상 건 타임라인 기록은 이상 대응 규칙(취소 표시)을 그대로 따라요.

### C8. 근무 시간 나누기
- 인수인계: 근무조 **오전/오후/야간**. "내 직전 근무 시작 이후" 기록만 보여줌
- 이상 대응: **주간 09~18시 / 야간 18~09시**. 야간엔 당직에게 알림
- **제안:** 근무표 하나(오전/오후/야간)만 둬요. 이상 대응의 "야간"은 **야간 근무조 시간**으로 바꿔요. 실제 교대 시간은 **혜진원에 확인**해야 해요.

### C9. 긴급 알림은 누구에게
- 인수인계: 간호 담당 + **현재 근무조 전원** (푸시)
- 이상 대응: 주간 간호사·사무국 / 야간 당직 / 위험이면 원장님. 15분(위험 5분) 동안 확인 없으면 다음 사람
- **제안:** 이상 대응 표를 따라요. 같은 근무조 선생님은 푸시 대신 **인수인계 맨 위 긴급 칸**으로 봐요. 푸시가 너무 많으면 아무도 안 보기 때문이에요.

### C10. 37도대 "미열/주의"일 때
- 인수인계: 미열이면 **재측정 할 일 자동 생성** (가정)
- 이상 대응: 주의면 **재측정 안내만**, 이상 건은 안 만듦
- **제안:** 합쳐요. 주의면 이상 건은 안 만들고 인수인계에 **"재측정" 할 일을 30분 기한으로 자동 생성**해요. 재측정도 주의 이상이면 이상 건을 만들어요.

### C11. 데이터 이름 · 체온 저장 방식
- 별님 ID: `starId`(인수인계·아카이브) vs `residentId`(일정·이상 대응)
- 체온: 소수 `38.2`(인수인계) vs 정수 `382`(퀵 체온·일정·이상 대응)
- **제안:** 코드에서는 `residentId`와 **정수 ×10**으로 통일해요. 화면 단어는 계속 "별님"이에요.

### C12. "아동" 표현
- 퀵 체온 명세에 "돌봄 대상 아동"으로 적혀 있어요. 혜진원 거주인은 성인도 있어요.
- **제안:** 문서와 코드 설명은 **"거주인"**, 화면은 **"별님"**. 일정 명세도 이미 이렇게 따르고 있어요.
