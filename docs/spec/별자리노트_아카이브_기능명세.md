# 별자리노트 · 휴대폰 아카이브 구현 명세
혜진아 왜요쌤 | 담당: 범수 | 모바일 통합용 v2 · 2026.11.12

**한 문장 정의**: 별님 한 명을 선택하면, 선생님들이 남긴 체온·관찰 기록과 그 별님에게 해당하는 반 공지를 한 타임라인에서 다시 찾을 수 있다. 담임이 바뀌어도 이전 기록자와 당시 내용은 그대로 남는다.

## 0. 다섯 ZIP을 합칠 때 먼저 읽을 것
이 폴더는 **설치 앱의 한 기능**을 정의한다. HTML은 상호작용 참고용, PNG는 주요 화면을 나란히 재구성한 안내도, 이 문서는 구현 기준이다. 기존 앱의 화면 이동·공통 저장소·사용자·별님 ID·권한 체계를 재사용한다. PC 대시보드와 독립 아카이브 서버는 이 기능의 산출물이 아니다.

1. 공통 하단 메뉴는 **인수인계 / 퀵 체온 / 일정**으로 둔다. 다섯 기능을 다섯 하단 탭으로 해석하지 않는다. 아카이브는 별님을 누르면 열리는 상세 화면이다. 알림은 알림 담당의 진입 규칙을 따른다.
2. **인수인계 v2의 별님 아카이브와 이 화면은 하나로 합친다.** 목록·상세·검색 UI는 이 명세를, 명시적 확인·메모 작성·할 일 완료 규칙은 인수인계 명세를 따른다. 동일 화면을 두 번 등록하거나 새 읽음 테이블을 만들지 않는다.
3. 체온 값·판정·정정은 체온 원본, 이상 건 진행/종료와 알림 확인은 이상 대응 원본, 일정은 일정 원본이 결정한다. 아카이브는 각 원본에서 필요한 표시값을 읽고 원래 기능으로 연결한다. HTML에 남아 있는 타 파트 보조 시연 코드를 실제 앱으로 복제하지 않는다.
4. 예시 이름이 서로 다르다(인수인계: 은하수자리 서준 / 퀵 체온·일정: 양자리반 이서준 등). **이름이 비슷하다는 이유로 같은 사람으로 병합하지 않는다.** 통합 시 한 개의 가상 명단을 선택하고 모든 화면을 같은 별님 ID로 시드한다. 아래 ‘서준’은 단독 시연용이다.

## 1. 누가 언제 쓰나
- 생활관 선생님: 교대 후 서준 별님의 오늘 체온과 당시 메모를 본다. 기록을 열기만 해도 업무를 마친 것으로 처리되면 안 된다.
- 새 담임: “낯선 소리에 놀랐을 때 어떻게 도왔지?”라고 생각하고 ‘소리’를 검색한다. 2025년 기록에서 당시 담임의 관찰을 찾는다.
- 한 반 선생님: 반 공지를 다른 별님 카드에서도 볼 수 있다. 같은 공지를 여러 번 확인할 필요가 없다.

## 2. 모바일 진입과 뒤로 가기
| 출발 | 누르는 곳 | 도착 / 복귀 |
|---|---|---|
| 인수인계 → 별님별 기록 | 반 선택 → 별님 카드 | 선택한 별님의 타임라인. ‘‹ [반] 별님 목록’은 같은 반 목록으로 복귀 |
| 인수인계 → 최신 기록 | 기록에 붙은 별님 이름 | 같은 타임라인을 연다. 통합 앱의 시스템 뒤로 가기는 실제 출발 화면으로 복귀 |
| 별님카드 | ‘이 별님의 기록 아카이브’ | 같은 별님 ID로 같은 목록을 표시. 별님카드용 복사본 생성 금지 |
| 타임라인 | 기록 하나 / 기록 찾기 | 휴대폰 안에서 하단 시트가 올라온다. 닫기·뒤로는 시트만 닫는다 |
| 아카이브 → 기록 남기기 | ‘○○ 별님 기록 남기기’ | 기존 인수인계 작성 시트를 해당 반·별님으로 미리 선택해 연다. 저장은 원본에서 한 번만 수행 |

**시연 파일 첫 화면**은 경로를 미리 진행한 ‘은하수자리 → 서준 → 기록 아카이브’다. 앱 전체의 시작 탭을 바꾸라는 뜻이 아니다. 넓은 브라우저에도 휴대폰 모형을 표시한다. 작은 휴대폰에서는 설명판과 가짜 상태바를 감추고 앱 화면이 폭을 채운다. 시연용 좌우 설명·바로가기 버튼은 설치 앱에 넣지 않는다.

## 3. 화면별 UI·버튼
| 화면 | 표시 | 행동 / 결과 |
|---|---|---|
| A. 별님 목록 | 반 탭, 아바타, 별님 이름, 기록 수. 반 색과 선택 테두리 | 반 선택 시 그 반 목록만 표시. 별님 변경 시 검색어·기간·범위 초기화 |
| B. 별님 타임라인 | 별님 아바타, 이름, 반, 현재 담임, 전체 건수·첫 기록 연월. 흰 카드 안에 제목·범위 필터·‘기록 찾기’·날짜별 타임라인 | 날짜 내 최신 시각부터. 화면 전체가 아니라 본문이 스크롤되고 하단 내비게이션은 유지 |
| B-1. 범위 선택 | **모두 / 이 별님 기록 / 반 공지** 및 건수 | 개인 체온·관찰은 ‘이 별님 기록’, 반 전원에게 쓴 공지는 ‘반 공지’. 시설 전체 공지는 제외. 선택한 범위가 0건이어도 버튼은 유지 |
| B-2. 기록 행 | 시간·작성자·종류·내용·확인 표시. 관찰은 초록 점, 체온은 원본 상태색과 글자. 반 공지는 점선과 ‘반 공지’ 문구 | 누르면 상세. 사진이나 할 일이 붙은 원본은 통합 시 허용 범위에서 상세에 노출. 기록 행은 읽음·투약·할 일 상태를 바꾸지 않는다 |
| B-3. 담임 변경 | ‘2026년 3월 · 담임 박지은 → 이수진’ 구분선 | 조건에 맞는 이전 담임 기록 앞에 한 번. 반 공지만 보는 경우 생략. 기록 수 제외 |
| C. 기록 찾기 | 검색어(최대 80자), 전체 기간 / 최근 7일 / 최근 30일, 조건 초기화, 결과 보기 | 적용 전은 임시값. ‘결과 보기’ 또는 검색어 입력 후 Enter로 적용. 닫으면 기존 조건 유지. ‘조건 초기화’는 같은 별님의 모두·전체 기간·빈 검색어로 즉시 복귀 |
| D. 기록 상세 | 별님 또는 ‘반 전원’, 기록 종류, 발생 날짜·시각, 당시 기록자, 본문, 출처, 읽음 상태. 연결된 할 일이 있으면 상태 표시 | ‘목록으로’ 또는 닫기로 돌아가면 범위·기간·검색어·스크롤 유지. 상세에서 체온 판정이나 알림 상태를 다시 계산하지 않는다 |

**검색 규칙**: 앞뒤 공백 제거 → 내용·기록자·종류에서 부분 일치 → 기간과 동시에 적용 → 범위별 건수 계산. 기간은 기관 현지 날짜 기준, 오늘 포함 최근 N개의 달력 날짜. 결과를 날짜 내림차순·시각 내림차순으로 정렬하고 동시각은 원본 키로 안정 정렬한다. 결과가 없는 날짜 제목은 감춘다. 프로필 전체 건수는 필터와 무관하고, 필터 건수는 현재 검색 조건을 반영한다.

## 4. 설정값과 상태 변경
| 항목 | 모바일 기본값 | 유지 / 초기화 |
|---|---|---|
| 대상 | 진입 경로에서 받은 별님 ID | 목록 복귀 시 반 유지. 외부에서 다른 별님으로 진입하면 이전 별님의 내용을 비운다 |
| 범위 / 기간 / 검색어 | 모두 / 전체 기간 / 비어 있음 | 상세 열고 닫을 때 유지. 새 별님 진입·명시적 초기화 시 기본값 |
| 읽음 | 현재 직원과 원본 기록 ID의 기존 확인 상태 | 열람만으로 변경 없음. ‘새 기록 확인’은 기존 인수인계 확인 동작을 호출. 다른 직원의 확인은 그대로 |
| 읽음 선 | 필터 없는 ‘모두’에서 마지막 새 기록 다음 | 범위·검색·기간으로 일부만 보일 때는 일괄 확인 숨김. 보이지 않는 검색 결과까지 확인되는 실수를 방지 |
| 알림·할 일 | 원본 상태 표시 | 기록을 읽는 것, 업무를 완료하는 것, 위험 알림을 수신 확인하는 것은 서로 다르다 |
| 정렬 / 시간 | 최신순 고정 / 기관 현지 시각 | 정렬 설정을 따로 두지 않는다. 단독 시연 날짜는 2026-10-28, 통합 앱은 실제 시계 또는 공통 시연 시계를 쓴다 |

단독 HTML은 메모리 안에서 동작한다. 새로고침·‘처음 상태로’는 시드로 복귀한다. **설치 앱의 확인 상태와 이미 저장한 기록은 앱을 닫았다 열어도 남아야 한다.** 기존 공통 저장소로 처리하고 HTML의 임시 상태를 영속 데이터로 사용하지 않는다.

## 5. 모듈 간 계약
| 기능 | 아카이브가 받는 것 | 아카이브에서 돌아가는 동작 |
|---|---|---|
| 인수인계 | 개인 관찰·반 공지, 작성자, 확인자, 할 일, 별님 ID | 명시적 확인은 기존 확인 처리 사용. 새 메모는 기존 작성 시트로 위임. 같은 공지를 어느 별님에서 확인해도 최신 기록에 반영 |
| 체온 | 원본 측정 ID, 별님 ID, 측정 시각, 값·단위, 당시 판정·기록자 | 성공적으로 저장된 값만 한 건 표시. 재측정은 별도 측정 ID, 정정은 같은 ID의 최신 버전. 판정 미제공 시 수치만 표시 |
| 알림·이상 대응 | 측정 ID와 연결된 caseId 및 열람 가능한 상태/종료 요약(제공될 때) | [통합 확장] ‘대응 이력 보기’는 해당 caseId를 원본 상세로 전달. 앱의 알림 재발송·담당 지정·종료 처리 없음 |
| 일정 | 공통 별님 ID. 선택적으로 측정 원본에 연결된 일정 라벨 | 예정된 측정을 기록으로 세지 않는다. 일정 수정·파일 업로드 동작 없음 |
| 공통 | 현재 직원·기관·열람 가능한 반·별님 명단·당시 소속 이력 | 접근 권한은 공통 계층에서 확인. 기기용 시연에서는 가상 시드만 사용 |

권장 화면 인자: `Archive(starId, origin, optionalRecordId)`. 권장 조회 항목: `recordKey, sourceKind, sourceId, scope, starId/classId, occurredAt, authorId, authorLabel, type, body, readState`; 선택값: `measurementId, caseId, taskRef`. 이름·반 이름은 표시용. 임의의 새 API 명칭은 강제하지 않는다.

예: 측정 M17을 기반으로 인수인계 H9가 생성됐다면 아카이브에는 **M17 한 건**을 표시하고 H9는 확인·할 일 참조로 연결한다. 개인 상세에도 반 공지 C4를 별님마다 복사하지 않는다. 조회 키는 ‘개인 대상 일치 또는 공지 시각에 그 반 소속’이며 입반 전 반 공지를 제외한다. 전반 후 과거 공지는 현재 열람 권한도 함께 검사한다. 담임 교체가 개인 기록 삭제 조건이 되어서는 안 된다.

## 6. 예외·접근성·설치 시 확인
- 초기 로딩: 선택한 별님의 이름과 로딩 상태만 표시한다. 반/별님을 빠르게 바꿔도 이전 응답이 새 목록을 덮지 않게 한다.
- 원래 기록 0건: “아직 기록이 없어요.” 검색으로 0건: “조건에 맞는 기록이 없어요”와 ‘전체 기록 보기’. 서버 실패: “기록을 불러오지 못했어요” + 재시도. 실패를 0건으로 표시하지 않는다.
- 읽음 저장 실패: 성공 표시를 되돌리고 재시도. 중복 탭은 단일 처리. 권한이 사라지면 목록·상세·건수와 임시 검색 상태를 비우고 목록으로 복귀한다.
- 색만으로 구분하지 않는다. 종류·상태는 글자로도 표시하고 반 공지는 점선을 더한다. 설치 앱 터치 영역 최소 44×44, 화면 확대와 긴 이름에서 줄바꿈, 기기 상·하단 안전 영역과 키보드를 고려한다.
- 설치 앱에서 Android 뒤로 가기: 키보드 → 열려 있는 시트 → 진입 화면 순. 시트 밖의 항목은 스크린리더 탐색에서 제외하고 닫으면 누른 버튼으로 초점을 돌린다.
- 연결이 없는 단독 HTML에서는 퀵 체온·일정 버튼에 통합 안내만 표시한다. 설치 앱에서는 실제 팀원 화면으로 이동해야 한다. 예외·권한·저장 실패·기기 재실행은 실제 통합 앱에서 별도 검수한다.

| 4 | 반 공지 → 08:40 공지 열기 | ‘은하수자리 전원’ 대상. 개인 기록에는 포함되지 않음 |
| 5 | 모두 → 새 기록 확인 → 같은 반 도윤 카드 → 최신 기록 | 서준의 개인 기록·은하수자리 공지만 공유 확인 처리. 도윤 개인 메모는 미확인 유지. 업무 완료나 이상 대응 상태 변화 없음 |
| 6 | 서준 카드에서 ‘서준 별님 기록 남기기’ → 관찰 메모 저장 | 대상이 서준으로 미리 선택됨. 아카이브와 인수인계에 같은 기록이 보이고 개인 기록 수는 한 건만 증가 |
| 7 | **통합 앱**에서 퀵 체온 저장 → 이 별님의 아카이브 → 앱 종료 후 재실행 | 실제 측정 한 건만 추가. 동일 별님의 기록과 확인 상태 유지. 측정 예정 일정은 추가되지 않음 |

**우선 구현**: 별님 선택 → 개인/반 타임라인 → 검색·상세 → 공통 확인 상태. 이상 대응 상세 링크는 원본 ID와 해당 화면이 준비된 뒤 연결해도 시연 가능하다. 본 ZIP은 APK나 완성 앱이 아니며, 폰 프레임·설명판·고정 날짜·가상 시드를 제품 화면으로 이식하지 않는다.
