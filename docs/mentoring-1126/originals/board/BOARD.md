## 11. 완료 기준

현재 화면 기준:
1. 36명이 표에 모두 나오고 10명씩 넘겨 볼 수 있다. 생활관 탭을 누르면 해당 인원만 나온다.
2. 이상 별님은 표 맨 위, 붉은 행으로 보이고 카드 ②·생활관 타일 건수와 같다.
3. 이상 별님의 대응 현황 칸에 의료호출 연결됨/관찰 중이 표시된다.
4. 같은 별님이 하루에 여러 번 측정돼도 재실·정상 인원은 한 명으로 센다.
5. 화면을 열고 닫아도 대응·호출 상태는 바뀌지 않는다 (보기 부분).

## 13. 시안과 실제의 차이

- 시안은 단일 HTML이며 **현재 화면을 그대로** 재현했습니다. 제안은 넣지 않았습니다.
- 시안의 시각은 11:31 기준이라 위치·일과가 "자유 시간"입니다(실제는 시간이 지나면 바뀜).

- 버튼은 눌러도 동작하지 않습니다 (생활관 탭과 페이지 넘김만 동작).
- 글꼴 Pretendard는 포함하지 않아 기기 글꼴로 보입니다.
