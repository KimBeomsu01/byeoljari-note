# 별자리노트 화면 디자인 기준 (v2, 2026-11-12)

**팀 시제품의 배치·모양을 따르고, 색은 혜진원 홈페이지 색(연분홍 바탕·혜진원 초록·갈색 글자·코랄·QUICK MENU 주황), 글자는 중장년 선생님에 맞게 한 단계 키운다.** 색 값은 `lib/core/theme.dart`가 기준이다.
시제품 원본: OneDrive `별자리노트_v2/` 안의 각 기능 `*_화면시제품.html` 과 `*_화면미리보기.png`, 인수인계 명세 13장(디자인 토큰).

| `T.headline` 화면 제목 | 24 | 20~22 |

- 14보다 작은 글자 금지.

## 모양
- 카드 모서리 13, 시트 위 모서리 26, 버튼 모서리 12, 칩·상태 표시는 완전히 둥글게.
- 그림자 없이 옅은 테두리. 카드는 흰 바탕.
- **누르는 것 높이 48 이상** (시제품 40 → 앱 기준 44 이상).
- 별님은 **얼굴 그림**(`FaceAvatar.resident` / `ResidentAvatar(residentId:)`), 직원도 `FaceAvatar.staff`.
- 시제품의 작은 알약 표시를 쓴다: "오전 ✓ 36.5° 평소", "새 기록", "지금".

## 배치
- 상단: 작은 '별자리노트' + ✦ 큰 제목 (app.dart). 하단: 인수인계 · 가운데 짙은 동그라미 '퀵 체온' · 일정.
- 화면 좌우 여백 20. 카드 사이 10~12.
- 시제품의 배치를 우선: 일정은 2열 카드, 이상 대응 '할 수 있는 일'은 2열 버튼, 체온 칸은 알약.
- 한 줄에 정보가 너무 많으면 줄을 나눈다. 점(·)은 한 줄에 최대 1~2개.
