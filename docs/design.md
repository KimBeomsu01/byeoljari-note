# 별자리노트 화면 디자인 기준 (v1, 2026-11-12)

## 누구를 위한 화면인가
- **40~60대 생활관 선생님.** 근무 중 서서, 한 손으로, 짧게 본다. 돋보기 없이 읽혀야 한다.
- 한 번 보고 "누가, 몇 도, 지금 뭘 해야 하는지"가 보여야 한다. 꾸밈보다 읽힘이 먼저다.

## 색 (`lib/core/theme.dart`)
| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| 밤하늘 남색 `brandDark` | #1E3A66 | 주 버튼, 선택된 탭·칩, 링크 |
| 새벽 하늘 `paper` | #EEF2F7 | 화면 바탕 |
| 흰 `surface` | #FFFFFF | 카드, 시트 |
| 글자 `inkMain` | #142033 | 본문 |
| 보조 글자 `inkSub` | #3D4A5C | 시각·작성자 등. **이보다 옅은 회색 글자는 쓰지 않는다** |
| 선 `line` | #C6D0DC | 테두리, 구분선 |
| 별빛 노랑 `starYellow` | #F5C518 | **가운데 '체온 재기' 버튼과 '새 기록' 표시에만** |
- 판정 색은 통합 명세 5-4를 따른다. 글자색(ink)만 대비를 높이려고 조금 진하게 했다.
- 색만으로 뜻을 전하지 않는다. 항상 기호(✓ ! ▲ ⚠ ▼)와 글자를 같이 쓴다.

## 글자 (`T`)
| 역할 | 크기 | 예 |
|---|---|---|
| 보조 `T.caption` | 15 | 시각, 작성자, 장소 |
| 본문·버튼 `T.body` | 17 | 기록 내용, 버튼 글자 |
| 제목 `T.title` | 20 | 별님 이름, 카드 제목, 구역 제목 |
| 화면 제목 `T.headline` | 24 | 상단 제목 |
| 요약 숫자 `T.number` | 32 | 교대 요약 숫자 |
| 체온 `T.display` | 52 | 퀵 체온 숫자 |
- **15보다 작은 글자는 쓰지 않는다.** 줄 간격 1.45 이상.
- 굵기로 위계를 만든다 (본문 400, 강조 600~700, 제목 800). 기울임·대문자 없음.
- 체온 숫자는 고정폭 숫자(`FontFeature.tabularFigures()`).

## 누르는 것
- 모든 버튼·칩·탭 **높이 56 이상** (`tapHeight`), 아이콘만 있는 버튼은 48×48 이상 + 글자 라벨이나 툴팁.
- 화면의 주 행동은 **폭 전체 버튼** 하나. 같은 줄에 버튼은 최대 2개, 같은 폭.
- 버튼 이름은 동사로 무엇이 일어나는지: "확인했어요", "체온 재기", "기록 남기기".
- 위험한 행동(종료, 잘못 쟀어요)은 한 번 더 묻는다.

## 배치
- 화면 좌우 여백 20 (`Gap.page`). 카드 사이 12, 구역 사이 24.
- **한 줄에 한 가지.** "A · B · C"처럼 점으로 여러 정보를 이어 붙이지 않는다 (점은 한 줄에 최대 1개). 필요한 것만 남기고 줄을 나눈다.
- 카드 안 순서: ① 누구(별님 이름, 크게) ② 무슨 상태(판정 표시 + 체온) ③ 무엇을 할지(버튼). 작성자·시각은 맨 아래 보조 글자.
- 모양에 위계를 준다: 카드 둥글기 16, 버튼 14, 상태 알약은 완전히 둥글게. 그림자는 쓰지 않고 테두리로 나눈다.
- 화면 아래 떠 있는 버튼이 내용을 가리지 않게 목록 아래에 여백(120)을 둔다.

## 말투
- 사용자 말로: "이상 대응 1건", "아직 아무도 확인 안 했어요", "평소보다 1.4도 높아요" (`plainDiff`).
- 개발자 말 금지: "필터", "어떤 필터에서도 맨 위", "범위", "기준 시각", "scope" 같은 말은 화면에 쓰지 않는다. ("보기"·"고르기"로)
- 빈 화면은 무엇이 없는지 + 할 수 있는 것: "남은 할 일이 없어요".

## 공통 부품 (`lib/core/ui.dart`)
`SectionTitle`, `InfoCard`(왼쪽 색 띠), `StageTag`, `StatusPill`, `ResidentAvatar`, `EmptyNote`, `plainDiff`, `hhmm`.

## 기억에 남는 한 가지
가운데 **노란 '체온 재기' 버튼**. 앱에서 가장 자주 누르는 것이라 가장 눈에 띄게 하고, 나머지는 조용하게 둔다.
