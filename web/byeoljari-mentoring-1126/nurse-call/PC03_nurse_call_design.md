# PC 03 의료 호출함 (간호 선생님용) — 디자인 명세

별자리노트 PC 웹의 의료 호출함 화면을 코드로 옮기기 위한 디자인 명세입니다.
값은 현재 디자인 캔버스의 마크업과 `tokens.css`, `pc.css`에서 그대로 옮겼습니다.
기능 동작은 기능명세를 따르고, 이 문서는 모양·크기·색·상태만 다룹니다.

- 기준 화면: 1920 × 1160, 최소 폭 1280px (그 아래는 가로 스크롤)
- 페이지 배경: `--gray-100` (#F2F4F6)
- 기본 글자: 16px / 1.5, `--font-sans`, 색 `--gray-900`, `-webkit-font-smoothing: antialiased`

### 4.1 머리

- `<button>`, 폭 100%, 왼쪽 정렬, 패딩 12px, radius 24px, 테두리 1px.

| 줄 | 내용 | 모양 |
|---|---|---|
| 1 | 반 이름 칩 | 패딩 0 6px, radius 12px, 9.5px/600. 바탕 `--gray-100`, 글자 `--gray-700` |
| 1 | 별님 이름 | 12.5px/700 |
| 1 | 나이 | 10.5px `--gray-500` |
| 1 (우측) | 호출 시각 | 10px/500 mono `--gray-500` |
| 2 | 호출 메시지 | 위 여백 6px, 11px `--gray-700`, 줄높이 1.375, 2줄 말줄임. 없으면 줄 자체 생략 |
| 3 | 담임 이름 | 위 구분선 1px `--gray-100`, 위 여백 8px + 패딩 6px, 11px |

- 담임 이름: 안 읽음 `--blue-500` / 700, 읽음 `--gray-600` / 400.
- 현재 캔버스의 이서준 카드는 반 이름 칩이 검은 바탕(`--gray-900`, 흰 글자)이고 시각이 빨간색 "10:11 (방금)"으로 남아 있습니다. 긴급 구분을 없앴으므로 다른 카드와 같게 맞출지 정해야 합니다.

### 4.4 카드 상태

| 상태 | 바탕 | 테두리 + 링 |
|---|---|---|
| 기본 | #FFFFFF | 1px `--gray-200`, 그림자 `0 1px 2px rgba(0,0,0,0.05)` |
| hover / focus-visible | `rgba(49,130,246,0.08)` | `--blue-500` + 링 `0 0 0 1px --blue-500` |
| 선택(활성) | `rgba(49,130,246,0.14)` | `--blue-500` + 링 `0 0 0 1px --blue-500` |
| 선택(비활성) | `--gray-100` | `--gray-400` + 링 `0 0 0 1px --gray-400` |

우선순위: 선택(활성) > hover > 선택(비활성). 비활성 선택 카드에 마우스를 올리면 hover 모양이 됩니다.

### 4.5 바닥 줄
- 패딩 10px, 위 테두리 1px, 흰 바탕, 11px. 왼쪽 "금일 누적 현황" `--gray-600`/500, 오른쪽 값 `--gray-900`/700 mono.

## 8. 접근성·구현 메모

- 누를 수 있는 것은 모두 실제 `<button>`, `<a>`, `<input>`으로 만들고, 입력칸에는 `<label>` 또는 `aria-label`을 붙입니다. 아이콘만 있는 버튼에는 `aria-label`(또는 `title`)이 필요합니다.
- 장식용 아이콘은 `aria-hidden="true"`.
- 현재 디자인에는 9.5 ~ 11px 글자와 `--gray-500`(#8B95A1) 흰 바탕 글자가 많습니다. 이 조합은 대비가 약 3:1이라 작은 글자 기준(4.5:1)에 못 미칩니다. 구현할 때 작은 보조 글자는 `--gray-600` 이상, 크기는 12px 이상으로 올리는 것을 권합니다.
- 빨간 글자(#F04452)도 흰 바탕에서 약 3.6:1이라, 작은 빨간 글자는 굵게 하거나 크기를 키워야 합니다.
- 버튼 높이 30 ~ 36px은 마우스 기준입니다. 터치 화면에서도 쓸 계획이면 44px로 키워야 합니다.
